## 懒人整合包（自用）

减少跑动和重复操作；全部 14 项功能均可在兼容的 Mod Config Menu 中独立开关并保存。

- 清房后吸取免费资源，金币、炸弹、钥匙、心类有独立拾取黑名单；心类默认关闭。
- 可选全房间吸取和开箱，仅处理可直达目标，不穿过障碍或沟壑。
- 智能普通箱与智能金箱分别控制；金箱默认保留两把钥匙，优先使用金钥匙或曲别针免费开启。
- 一键懒人模式、轻度辅助和恢复切换前配置；原配置备份可跨重启恢复。
- 接触交易防误触、普通便便/火堆一击清理、药丸识别、隐藏门高亮、离层遗漏提醒、镜子保护。
- 地图键临时暂停吸取/开箱；可选手动回溯与死亡自动回溯。

菜单路径：**L → 懒人整合包（自用）→ 懒人预设 → 一键启用懒人模式**。
新增全房间模式、金箱功能及回溯默认关闭；主动启用懒人预设会开启新的清房自动处理功能，保留你的黑名单和回溯选择。
回溯使用原版上一房间检查点，不提供任意时间点或多槽存档。

## 奶龙替换以撒

为普通以撒提供奶龙风格外观，包含四方向身体、行走/待机动作、飞行身体、部分道具联动表情、Boss 胜利大笑及笑声音频。

- 1.4.5 使用原生 Sprite 指针身份追踪，避免因 Lua 包装对象变化反复重载服装动画。
- 保留角色/幽灵转换时的服装恢复、控制状态感知的 Boss 庆祝、移动朝向开关和恢复默认配置。
- 不改动血量、属性、道具能力、攻击、碰撞箱、角色控制或 HUD。
- 可选 Mod Config Menu 分类：**NaiLong**。

## 安装

推荐通过上方 Steam 创意工坊链接订阅。

手动安装时，先完整退出游戏，将 `mods/baicha_qol` 或 `mods/baicha_nailong` 文件夹复制到游戏安装目录的 `mods` 下，再重启并启用。每个 Mod 只启用一份，避免本地版和订阅版重复加载。

本项目面向忏悔+，使用标准 Lua API，不依赖 REPENTOGON；懒人包面向单人及本地合作，不支持官方在线合作。核心功能无需配置菜单模组；调整设置可使用 [Mod Config Menu Chinese](https://steamcommunity.com/sharedfiles/filedetails/?id=2494192799) 或兼容版本。
